# QuickBite — Online Food Ordering System

A front-end Web Technology project built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern web browser.
3. Select food items, enter a name and phone number, and place a demo order.

## Host free with GitHub Pages
1. Sign in to GitHub and create a **public** repository (for example, `online-food-ordering`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then click **Save**.
5. Wait for the Pages deployment to finish. GitHub will show your public website URL in the Pages section.

## Important limitations
This is a browser-only demo. Orders are not sent to a restaurant, saved in a database, or connected to a payment service. A real production ordering system needs a backend, secure data handling, and deployment configuration.
